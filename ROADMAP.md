# RelayPulse Roadmap

## Q4 2026 (v0.2.0 - v0.3.0)
- [ ] Redis backend adapter (`RELAYPULSE_STORAGE=redis`) for high-throughput multi-node clusters.
- [ ] Automated subscriber health check probes while circuit breaker is in `OPEN` state.
- [ ] OpenTelemetry trace propagation headers (`traceparent`) injected into outgoing webhooks.

## Q1 2027 (v0.4.0)
- [ ] Lightweight React developer dashboard for visual DLQ inspection and event streaming.
- [ ] Multi-tenant isolation keys and per-tenant rate-limiting quotas.
